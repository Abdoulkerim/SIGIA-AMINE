# Étape 4 — Module Administration / Élèves — V1 opérationnelle

La première tranche frontend couvre :

- connexion Supabase Auth ;
- garde de route via `proxy.ts` ;
- contexte utilisateur/rôle ;
- tableau de bord initial ;
- liste des élèves ;
- création d'un dossier élève ;
- consultation d'un dossier élève ;
- respect du `school_id` et des policies RLS.

Le workflow métier complet de l'inscription, réinscription, parent/tuteur, affectation en classe et documents sera ajouté dans les sous-étapes suivantes.
