# Étape 2 — Seed officiel Al Amine

## Objectif
Créer les données institutionnelles minimales nécessaires au démarrage de SIGIA-AMINE sans inventer de données personnelles ni de listes de classes non fournies par le cahier des charges.

## Données incluses
- Établissement `AL-AMINE` / `Complexe Scolaire Al Amine`
- Paramètres français, XOF, fuseau `Africa/Ouagadougou`
- Année de développement `2026-2027` (à confirmer par la Direction)
- Trois périodes génériques `T1/T2/T3` (calendrier à confirmer)
- Types de documents administratifs explicitement prévus par le cahier

## Données volontairement absentes
- Élèves réels
- Parents réels
- Personnel réel
- Classes réelles
- Matières réelles
- Tarifs réels
- Comptes réels

Ces données viendront des données officielles validées par Al Amine.
